# 競合調査・市場ポジショニング分析

## 1. 調査の目的と分析軸

スマートフォンカメラ動画を用いた3次元動作解析・キネマティクス分析・コーチング支援アプリの開発にあたり、国内外の競合アプリ・研究プラットフォーム・従来型解析ソフトを調査し、既存市場の構造的ギャップ（ホワイトスペース）と本プロダクトの差別化戦略を明確化する。

### 評価・分析の6軸
1. **解析の次元・技術方式**: 2D / 単眼3D / 多眼3D、マーカーレス / マーカーベース / 古典的DLT法
2. **手法の柔軟性と座標編集**: トラッキング・モデリング手法の選択性、誤検出時の手動修正（Human-in-the-Loop）可否
3. **エビデンス・統計比較**: 査読文献に基づく競技別規範データ（平均・SD・傷害リスク閾値等）との比較機能
4. **コーチング・共有UX**: 現場での即時性、チーム・選手管理、LINE等の日常コミュニケーションアプリへの共有容易性
5. **運用環境・導入コスト**: スマホ完結性、オフライン対応、価格帯・ライセンス形態
6. **精度と信頼性**: バイオメカニクス研究基準（関節角度誤差、物理制約、透明性）

## 4. 市場の構造的ギャップ（ホワイトスペース）

競合調査から、以下の **3つの明確な断絶（ギャップ）** が存在する。

1. **「研究グレードの透明性・正確性」と「現場コーチングUX」の断絶**
   - `OpenCap` / `Pose2Sim` / `Frame-DIAS` は手法が透明で精度検証・手動補正・古典的DLT対応ができるが、現場のコーチや選手が日常的に使えるモバイルUXがない。
   - 逆に `SPLYZA Motion` や特化型アプリは手軽だが「ブラックボックス」であり、オクルージョンや高速動作でトラッキングが破綻した際に座標を修正して正しい力学値を得ることが難しい。
2. **「数値の可視化」と「科学的解釈（エビデンス比較）」の断絶**
   - 多くのアプリは「肘角度 92°」「体幹回旋速度 650°/s」といった数値を出すだけで終わる。
   - 現場のコーチ・選手が本当に知りたいのは **「この数値は最新のスポーツ科学文献のトップ選手・同年代統計と比べてどこに差があり、傷害リスクやパフォーマンス改善にどう繋がるのか」** である。
3. **「分析アプリ内完結」と「日本のチーム日常導線（LINE等）」の断絶**
   - 海外製アプリ（`OnForm`, `Uplift`）は独自チャット空間への囲い込みを前提とするが、日本を中心とした部活動・クラブチーム・パーソナル指導の現場では連絡インフラが **LINE** に集約されている。
   - 受け手（選手・保護者・外部トレーナー）がアプリ未インストールでも、LINE上のリンク/サマリーカード1タップで3D動作とエビデンス比較レポートを確認できる体験が決定的な導入障壁の低減になる。

## 5. 差別化戦略（Winning Strategy & Moat）

本プロダクトは **「研究レベルの3D動作解析パイプラインの柔軟性・修正可能性」×「最新エビデンスに基づく科学的フィードバック」×「LINE起点で回る現場コーチングUX」** の交差点にポジションを取る。

1. **Multi-Method Pluggable Engine（手法の選択肢と透明性）**
   - 用途（現場の即時フィードバック vs 精度重視の測定・研究）に応じて、**単眼AIマーカレス / 多眼AI＋三角測量 / 古典的マーカー＋DLT法** を切り替え可能にし、すべての解析結果に「使用手法・信頼度・キャリブレーション誤差」を明示する。
2. **Mobile-First Human-in-the-Loop 座標編集**
   - 深層学習モデルが外したフレームだけ信頼度ヒートマップでハイライトし、スマホ画面上で数タップ修正 → 自動補間＆逆運動学（IK）再計算できる体験を実現する。
3. **Evidence-Backed Benchmark Engine（文献エビデンス比較）**
   - 査読済みスポーツバイオメカニクス論文から構造化した「競技×動作×属性別」の規範データベースを内蔵し、個人のキネマティクス波形・主要指標をパーセンタイル/zスコアで対比、出典論文と改善アクションを提示する。
4. **Zero-Friction Sharing（LINE最適化レポート共有）**
   - チーム・選手管理と連動し、分析結果を「OGPリッチカード＋要約インフォグラフィック画像＋閲覧専用WebビューアURL」としてLINE等へワンタップ共有可能にする。
